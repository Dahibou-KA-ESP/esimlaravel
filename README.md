# Comparateur d'Assurance
## Description
Ce comparateur d'assurance est un outil conçu pour aider les utilisateurs à comparer différentes offres d'assurance disponibles sur le marché. Il permet de visualiser et d'évaluer les différents plans d'assurance en fonction de plusieurs critères spécifiques.

## Fonctionnalités principales
Comparaison des offres: Affichage des détails des différentes offres d'assurance.
Filtrage: Possibilité de filtrer les offres par type d'assurance, coût, couverture, etc.
Interface conviviale: Interface utilisateur intuitive pour une expérience utilisateur optimale.
